# Конспект ML Handbook: главы 13–23 простыми словами

Источник: [ML Handbook](https://mlhandbook-production.up.railway.app/parts/intro-ml/intro.html). Формат каждой главы: определения, формулы с «Обозначениями», блоки «Простыми словами» с числовыми примерами, практический пример, вопросы на собеседовании и список «что запомнить». Все числа в примерах пересчитаны вручную и проверены кодом.

## Как собирается пазл

```
13 Производная и градиент   → «куда крутить параметр, чтобы ошибка упала»
        ↓
14 Градиентный спуск        → «повторяем шаг против градиента» (шаг η, батчи, Adam)
        ↓
15 Линейная регрессия       → первая модель: ŷ = b + w·x, потери MSE/MAE/Huber, МНК
        ↓
16 Масштабирование          → чтобы расстояния, штрафы и спуск не зависели от единиц
17 Feature engineering      → как сделать из сырых данных хорошие признаки, и не подглядеть в ответ
18 Регуляризация            → штраф за большие веса: Ridge, Lasso, Elastic Net
        ↓
19 Логистическая регрессия  → то же, но для классов: сигмоида, LogLoss, softmax
20 SVM и наивный Байес      → «граница с максимальным зазором» и «вероятности по словам»
21 KNN                      → «спроси соседей» и быстрый поиск соседей (ANN)
22 Кластеризация            → искать группы без ответов
23 PCA                      → сжимать признаки, сохраняя главный разброс
```

## Мини-словарь математики (сквозной)

| Символ или слово | Как ребёнку |
|---|---|
| $f(x)$ | Автомат: число вошло, число вышло |
| $f'(x)$ | Наклон графика в точке («скорость изменения») |
| $\nabla f$ | Стрелка из наклонов по всем ручкам, смотрит туда, где функция растёт быстрее всего |
| $\sum$ | «Сложи всё по списку» |
| $\frac1n\sum$ | «Сложи и поделить на количество», то есть среднее |
| $\lVert v\rVert$ | Длина стрелки $v$ |
| $\hat y$ | Прогноз модели (шапка = «оценка») |
| $e^x$, $\ln x$ | Пара взаимно обратных операций: «возвести $e$ в степень» и «найти степень» |
| $\arg\min$ | «Значение, при котором достигается наименьшее» |
| $\mathbb E$ | «В среднем» |
| $X^\top$ | Таблица $X$, перевёрнутая: строки стали столбцами |
| Матрица | Таблица чисел |
| Вектор | Список чисел или стрелка |
| Дисперсия | Насколько данные разбросаны вокруг среднего |
| Гиперпараметр | Ручка, которую мы выставляем сами до обучения |
